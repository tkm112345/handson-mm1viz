# mm1viz

応用情報技術者試験の **M/M/1 待ち行列モデル**を、スライダーで操作しながら
視覚的に理解する Go 製 GUI アプリ。2つのタブで構成される。

- **Waiting Time タブ**：待ち時間 Tw が「サービス何回分か」を四角の並びで表示
- **Poisson タブ**：M/M/1 の「最初の M」＝到着数のポアソン分布を棒グラフで表示

到着率 λ は下部の**共通スライダー**で、両タブに効く。

理論的な背景（なぜ λ と μ が要るか、ポアソン到着とは、「頻度が決まっているのにランダム」の意味など）は [docs/theory.md](docs/theory.md) にまとめている。

## タブ1：Waiting Time

到着率 λ と平均サービス時間 Ts を動かすと、待ち時間 Tw が
「サービス何回分（四角いくつ分）か」として棒で表示される。

```
WAIT (Tw)                         SERVICE (Ts)
[■ ■ ■ ■ ■ ...............]        [■]
```

- オレンジの四角：待ち時間 Tw（四角1個 = サービス1回分 Ts）
- 緑の四角：サービス時間 Ts（1回分）
- ρ が 1 に近づくと待ちの四角が増え、`>>` で画面外へ

### M/M/1 の式

| 記号 | 意味 | 式 |
|------|------|----|
| λ | 到着率 | 入力（共通スライダー） |
| Ts | 平均サービス時間 | 入力 |
| ρ | 利用率 | ρ = λ·Ts （= λ/μ, μ=1/Ts） |
| Tw | 平均待ち時間 | Tw = ρ/(1−ρ) × Ts |
| W | 平均応答時間 | W = Tw + Ts = Ts/(1−ρ) |

「待ちはサービス何回分か」= Tw/Ts = ρ/(1−ρ)。**安定条件：ρ < 1**。

## タブ2：Poisson

M/M/1 の到着は**ポアソン過程**（＝到着数がポアソン分布）。
時間 t の間に k 件到着する確率を棒グラフで表示する。

$$
P(k) = \frac{(\lambda t)^k}{k!}\,e^{-\lambda t}
$$

| 記号 | 意味 |
|------|------|
| λ | 到着率（共通スライダー。1単位時間あたり平均何件来るか） |
| t | 観測時間（何単位時間ぶん数えるか） |
| λ·t | その観測時間の平均到着数（`mean`） |
| P(k) | ちょうど k 件来る確率 |

- λ または t を上げる → 平均 λt が増え、山が右（多い方）へ移動して広がる
- 下部に `mean = λt` と `P(0)`（1件も来ない確率）を表示
- ポアソン（回数）と指数分布（到着間隔）は同じランダム到着の裏表


## 使い方

- **λ スライダー（共通）** … 到着の勢い。両タブに効く
- **Waiting Time タブ / Ts スライダー** … 1回の処理時間。上げると待ち時間も伸びる
  - 例：Ts=0.2 のまま λ を 3→4→4.5（ρ=0.6→0.8→0.9）で待ちが 1.5→4→9 個分に急増
  - ρ ≥ 1（λ·Ts ≥ 1）で `UNSTABLE` 表示
- **Poisson タブ / t スライダー** … 観測時間の窓幅。上げると平均 λt が増える
  - 例：λ=2 で t=0.5→1→2 とすると P(0)=0.37→0.14→0.02（長く見張るほど「0件」は起きにくい）
