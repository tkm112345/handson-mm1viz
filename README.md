# mm1viz

応用情報技術者試験の **M/M/1 待ち行列モデル**を、スライダーで操作しながら
「待ち時間が何回分のサービス時間に相当するか」を視覚化する Go 製 GUI アプリ。

到着率 λ と平均サービス時間 Ts を動かすと、待ち時間 Tw が
「サービス何回分（四角いくつ分）か」として棒で表示される。

## 画面

```
WAIT (Tw)                         SERVICE (Ts)
[■ ■ ■ ■ ■ ...............]        [■]
```

- オレンジの四角：待ち時間 Tw（四角1個 = サービス1回分 Ts）
- 緑の四角：サービス時間 Ts（1回分）
- ρ が 1 に近づくと待ちの四角が増え、`>>` で画面外へ

## M/M/1 の式

| 記号 | 意味 | 式 |
|------|------|----|
| λ | 到着率 | 入力 |
| Ts | 平均サービス時間 | 入力 |
| ρ | 利用率 | ρ = λ·Ts （= λ/μ, μ=1/Ts） |
| Tw | 平均待ち時間 | Tw = ρ/(1−ρ) × Ts |
| W | 平均応答時間 | W = Tw + Ts = Ts/(1−ρ) |

「待ちはサービス何回分か」= Tw/Ts = ρ/(1−ρ)。**安定条件：ρ < 1**。

## 必要環境

- Go 1.21 以降 / デスクトップ環境ありの Linux
- システムライブラリ（Fyne / glfw が要求）:

```bash
sudo apt install gcc libgl1-mesa-dev xorg-dev \
    libwayland-dev wayland-protocols libxkbcommon-dev libdecor-0-dev
```

## 実行

```bash
go mod tidy
go run .
```

## 使い方

- **λ スライダー**を上げる → 待ちの四角が増える（混雑）
- **Ts スライダー**を上げる → 1回の処理が長くなり、待ちも実時間も伸びる
- ρ ≥ 1（λ·Ts ≥ 1）で `UNSTABLE` 表示

例：Ts=0.2 のまま λ を 3→4→4.5（ρ=0.6→0.8→0.9）と上げると、
待ちの四角が 1.5→4→9 個分と急増するのが体感できる。

## 使用ライブラリ

- [Fyne](https://fyne.io/) — GUI（ウィンドウ・スライダー）
- [gg](https://git.sr.ht/~sbinet/gg) — 四角・線を描いて時間バーを生成

## 既知の制限

- 画面の文字は英字のみ（gg の既定フォントが日本語非対応）。
  日本語化するには `gg.LoadFontFace` で日本語 TTF を読み込む必要がある。
